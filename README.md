## Sobre o projeto
O Sistema_Biblioteca é um sistema de gerenciamento escolar desenvolvido para automatizar a organização do acervo e o fluxo de empréstimos de uma biblioteca de ensino.

### Objetivo do Projeto

Desenvolver uma plataforma centralizada e intuitiva para automatizar o controle do acervo e otimizar todo o fluxo de empréstimos e devoluções da biblioteca escolar.O sistema busca reduzir o trabalho manual da equipe pedagógica, mitigar erros de inventário e garantir que alunos e professores tenham acesso rápido e organizado aos materiais didáticos e literários, promovendo uma gestão eficiente e baseada em dados.
